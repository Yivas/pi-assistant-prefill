# Code of Conduct

Keep issues, pull requests and project discussions focused on the work. Critique proposals rather than people, explain disagreements with evidence and respect a contributor's decision not to share personal information.

Harassment, threats, discriminatory attacks against participants, doxxing and posting private conversations or credentials are not acceptable. This applies to project spaces and to public representation of the project.

The maintainer may edit or remove content, close a thread, restrict participation or block an account when necessary. Decisions should reflect the behavior and its impact, not a participant's background.

For a non-sensitive moderation concern, contact the maintainer through a project issue without repeating harmful content. For concerns involving private data, ask for a private contact without posting identifying details. Security vulnerabilities use the channel in [SECURITY.md](SECURITY.md). No response deadline is promised.
